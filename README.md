# 🎡 Wheel of Fortune
## 跨平台幸运转盘抽奖应用 | Flutter

一款使用Flutter构建的精美跨平台幸运转盘应用，提供流畅的物理旋转动画、完全可自定义的奖项配置，一套代码即可同时运行在iOS、Android、Web及桌面平台。

## ✨ 核心特性
- 基于CustomPaint的高性能矢量转盘绘制
- 带阻尼效果的真实物理旋转动画
- 支持自定义奖项数量、颜色、图标和概率
- 可配置的旋转速度、时长和停止位置
- 跨平台一致的用户界面和交互体验
